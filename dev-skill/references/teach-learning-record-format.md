# Learning-record format

Learning records live under `learning-records/` as sequential
`NNNN-<slug>.md` files. Record demonstrated understanding, relevant prior
knowledge, a corrected misconception, or a mission change. Do not record mere
lesson coverage or a session log.

```md
# <short title>

<one to three sentences: what was learned or established, and why it changes
future teaching>
```

When a later record supersedes an earlier understanding, mark the old record as
superseded instead of deleting it.

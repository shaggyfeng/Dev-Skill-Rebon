# Teaching resources format

```md
# <Topic> Resources

## Knowledge
- [high-trust source](https://example.invalid/source)
  <what it covers and when to use it>

## Wisdom
- <community, practitioner, or real-world practice>
  <what it can teach that a source cannot>

## Gaps
- <important topic without a trustworthy source>
```

Prefer primary sources, official documentation, recognised experts, and
peer-reviewed work. Annotate every entry and remove sources that prove shallow
or off-mission.

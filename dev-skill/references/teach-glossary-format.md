# Teaching glossary format

`GLOSSARY.md` is the canonical language for a teaching workspace. Add a term
only after the human demonstrates understanding; it is not a dictionary of
things not yet learned.

```md
# <Topic> Glossary

## Terms

**<Term>**:
<one or two sentence definition>
_Avoid_: <ambiguous aliases>
```

Choose one preferred term, keep definitions tight, use glossary terms inside
later definitions, and revise a definition when understanding improves.
